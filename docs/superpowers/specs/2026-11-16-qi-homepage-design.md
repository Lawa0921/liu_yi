# 首頁改版設計：「氣聚成人」

日期：2026-11-16
狀態：使用者已核可方向（內容接法 1、字型 A），授權直接交付完成版本
前一份設計：`2026-11-15-astro-rewrite-design.md`。本文件取代其中首頁（首屏、三幕、立體場景）的部分；其餘頁面與內容模型沿用。

## 1. 為什麼要改

- **業主與使用者的要求**：酷炫 7–8 分（滿分 10），不要水墨範本，參考鬼武者官網的衝擊感。
- **前三版首頁仍被評「偏普通」**：首屏大圖、分段捲動、卡片排一排，效果只是貼在一般官網的骨架上。
- **試作已獲肯定**：`/lab/qi/` 的「氣聚成人」，使用者評「看起來不錯」。
- **使用者提的兩個問題**：
  1. 要考慮怎麼跟具體內容整合。
  2. 現在的字型（Noto Serif TC 粗）跟傳統武術沒關聯、突兀。

## 2. 目標

1. 首頁整個骨架改成一個由金色光點組成的八極拳師當主角。內容跟著拳師的招式長出來，不是貼在旁邊。
2. 使用者已選定「招式就是課程目錄」：
   - 往下捲，拳師一式一式打下去，每一式對應一門課。
   - 大人／小孩切換時，光點散開，重聚成另一組架勢。
   - 師資段：光點聚成教練剪影。
   - 收費、課表段：光點退成背景的氣，資訊清楚浮在上面。
   - 結尾：光點收進一顆朱印，印就是「LINE 預約」按鈕。
3. 全站字型改用全字庫正楷體 TW-Kai（使用者選 A）。
4. 手機也要有同樣的骨架與記憶點。

## 3. 非目標

- 不重做課程內頁、教練內頁、場地、收費、課表這些獨立頁的版面，只換字型與小幅調整。
- 不做聲音。
- 不做 webcam 互動。
- 不用動作捕捉。

## 4. 反目標（做到了也算失敗）

- 光點很美，但找不到課程、收費、課表或 LINE 預約。
- 為了效果鎖住捲動（強制 scroll-snap 綁架捲動、捲不動、手機網址列一伸縮就跳）。
- 中低階手機發燙、卡頓，或首屏白畫面很久。
- 失去 SEO：課程名、師資、收費等文字只存在 canvas 裡。
- 回到禁用語彙：
  - 太極圖、八卦圖（含卦爻）、龍鳳
  - 日式語彙
  - 假書法
  - 水墨範本感
  - 金色漸層立體字
  - 外發光滿版
  - 彩色技能特效

## 5. 限制

- **技術**：
  - Astro 7 靜態輸出，部署在 GitHub Pages。
  - 用 `deploy-target.mjs` 管理 site、base、outDir。
  - three@0.187 與 gsap 3.15 已安裝。
- **效能**：
  - 首屏傳輸 ≤1.5 MB，目標 ≤1.3 MB；整頁 ≤5 MB。
  - three 的 chunk gzip 約 152 KB，必須在首屏載入。這是新骨架的前提，所以需要一個在 three 到達前就成立的首屏，見 §8.4。
- **品質**：
  - 依專案 AGENTS.md 走 TDD。
  - 既有測試依賴的選擇器要保留，或在測試裡同步遷移並說明。
  - 驗收派 fresh-context agent。
  - 測試只用 in-process 驅動，**禁止 OS 層級滑鼠鍵盤自動化**。
- **字型授權**：
  - 全字庫正楷體 TW-Kai 有兩種授權可選：「政府資料開放授權條款-第1版」或「OFL-1.1」。我們選 OFL，可子集化。
  - 來源：https://data.gov.tw/dataset/5961
  - 子集化後依實際用字產生 woff2。授權聲明放進 repo。
- **素材**：
  - 剪影在 `src/assets/silhouettes/`，是 AI 生成。八極拳架是否正確待業主確認，每個架勢都要能單獨抽換。
  - 生圖管線：OpenAI Images API（`gpt-image-1.5`），腳本在 scratchpad 的 `silhouettes-raw\`。

## 6. 考慮過的做法

| 做法 | 內容 | 結果 |
|---|---|---|
| 1. 招式就是課程目錄 | 拳師全程是主角，每一式帶出一門課；大人／小孩、師資、收費、課表、預約都用光點的變化轉場 | **使用者選定** |
| 2. 開頭演武，後面回到一般排版 | 最好讀、工最小 | 後半段又會變普通，未採用 |
| 3. 拳師常駐一側，內容在另一側翻 | 一直有拳師 | 手機只能上下疊，長表格太窄，未採用 |

字型考慮過三組，內文都用全字庫正楷：

| 組合 | 大標 | 結果 |
|---|---|---|
| A | 全字庫正楷體 | **使用者選定** |
| B | 教育部隸書 | 武術感最強，但商用要先向教育部書面申請。可作為日後升級：申請通過後只換大標字型 |
| C | 昭源宋體 900 | 太像現在的印刷宋，未採用 |

## 7. 首頁段落與內容對應

以下是使用者已選定的結構。段落順序與文案是我的提案，可再調。

| # | 段落 | 光點形體 | 浮出的內容（DOM 文字，可被搜尋與讀屏） |
|---|---|---|---|
| 0 | 開場 | 吸氣聚成「震腳抬腳」→ 落地（`fig-zhenjiao` → `fig-zhenjiao-land`），地面衝擊波 | 直書「六藝武術」、副標「八極拳・兵器・格鬥」、往下捲提示 |
| 1 | 大人・拳 | 頂肘（`fig-dingzhou`） | 八極專修：課名、兩行介紹、「看這門課」 |
| 2 | 大人・格鬥 | 護架（`fig-guard`；2026-11-20 依業主要求由八極的撐捶 → 貼山靠改成拳擊／散打的實戰架式；同日業主再要求刪掉第二式直拳 `fig-jab`，大人格鬥只剩一段，`combat-b` 只屬於小孩，大人頁面上整段不出現、後面兵器的序號改成三、四、五） | 散手技擊 |
| 3 | 大人・兵器 | 劍 → 苗刀 → 大槍（三件兵器的光點） | 中式兵器。三件兵器各有一行子項；最後一件聚成後可接正式站的 3D 金屬兵器（見 §8.6） |
| — | （小孩組） | 切到小孩時，第 1–3 段換成兒童形體（新素材，見 §9） | 第 1 段換兒童武術、第 2 段換防身格鬥、第 3 段換防身兵器 |
| 5 | 其他課程 | 光點淡成一列小形體，不搶戲 | 巴西柔術、核心瑜珈（`category: other` 且 `published: true`） |
| 6 | 師資 | 依序聚成每位教練的剪影（見 §9） | 教練名、職稱、專長、「看教練」；只顯示 `published: true` 的教練 |
| 7 | 收費、課表 | 光點退成背景的低亮度氣流 | 不含金額與時段的導引文案（例如「大人、兒童分班，月繳與堂數方案」），加「看收費」「看課表」連到既有頁；另有場地一行介紹與連結。金額與時段目前只有海報圖，沿用既有規定「不轉成文字，避免抄錯」 |
| 8 | 預約 | 全部光點收進一顆朱印 | 朱印刻館名「六藝」（篆字取樣）。印旁是 DOM 文字按鈕，文字沿用 `BOOKING_LABEL`，點了開啟既有的 `#line-dialog`；地址、聯絡資訊放頁尾 |

**大人／小孩的切換規則**（我的決定）：
- 小孩課程不另開段落，而是換掉第 1–3 段的內容。頁面長度不變。
- 預設顯示大人。切換鈕在第 1–3 段期間黏在畫面上方（sticky），離開課程段就收起。頁首不另加大人／小孩快捷。
- 切換時光點散開，重聚成另一組形體，DOM 內容同時換組。
- 兩組課程的 DOM 都存在頁面上。非作用中的那組以 `hidden` 處理，但仍是可抓取的連結。另在第 5 段加一行「所有課程」連到課程總覽頁。這樣可以守住「每門已發布課程都有 DOM 標題與連結」。
- 既有的 `data-audience-option`／`data-audience-panel` 與記住選擇的行為要保留。

## 8. 技術設計

### 8.1 光點引擎
從試作 `src/lab/qi/` 升級為正式模組。
- GPGPU：`GPUComputationRenderer`，位置與速度兩張貼圖，目標形體一張貼圖。
- 力場：
  - 彈簧吸回目標
  - curl noise 煙流
  - 掌風（滑鼠或手指拖曳）
  - 換招衝量
- 光點數：桌機約 6.5 萬點，手機或觸控約 2 萬點。依實測 fps 自動降級（連續低於 40 fps 就降一級）。
- 試作已知要補強的地方：
  - 換招時的拖尾（沿速度拉長的點），讓炸開有方向。
  - 落地衝擊波要更強。
  - 開場「吸氣」要有往中心的流線。
  - 大槍桿身加粗、紅纓顯紅。

### 8.2 形體資料
- 剪影取樣與兵器取樣都在**建置時**預先算好，輸出成二進位檔（每個形體一個 Float32/Float16 檔）。執行時只下載不計算。
- 人形比例用「頭部大小」對齊，腳底對齊。比例表集中在一個設定檔，試作中的 `FIGURE_SCALE` 要搬過去。
- 兵器取樣改用 build 時的固定幾何快照，不要每次 runtime 依賴 `weapons.ts`，避免兩條線互相牽動。

### 8.3 捲動
- **不用強制 scroll-snap**，改成一般捲動：用段落進度驅動形體插值，段中間是「散開到聚合」，段落停留區間內維持聚合。
- 段落是正常的 DOM `section`，文字用 Astro 渲染；canvas 是 `position: fixed` 的背景層。
- 手機網址列伸縮：高度用 `svh`／`lvh`，不在 resize 時重建模擬。

### 8.4 首屏在 three 到達前
- 首屏 HTML 先顯示文字：站名與副標，用 TW-Kai 子集。
- 背景放一張預先算好的「聚合拳師」靜態圖（建置時用 headless 截試作的終態，WebP，目標 ≤60 KB）。
- three 到達後，光點從靜態圖的位置接手，交叉淡化，不重播開場。
- 開場只在每個工作階段首次進站時演，沿用 sessionStorage。

### 8.5 退回與無障礙
- **減少動態**：顯示各段的靜態聚合圖；沒有掌風、沒有炸開。
- **無 WebGL 或模擬失敗**：每段顯示該形體的靜態圖。所有內容都是 DOM，完全可用。
- 鍵盤可跳過開場、可操作切換鈕與朱印。
- canvas 設 `aria-hidden`。

### 8.6 跟既有 3D 兵器的關係
- 首頁第 3 段不再放 three 的金屬兵器台；兵器由光點表現。
- 課程內頁（中式兵器、防身兵器）的 3D 兵器架保留不動。
- 第 3 段最後一件兵器聚成後，加一個「看真兵器」連到中式兵器課程頁。

### 8.7 字型
- 全站的 `--font-serif`／標題、內文、按鈕都改用 TW-Kai 子集。
- TW-Kai 只有一種粗細，所有用到它的地方設 `font-synthesis: none`，`font-weight` 一律 400，避免假粗體。
- 子集化：建置時掃描全站實際用字（含內容集合與元件內字串），只產生這些字的 woff2，不另加常用字底集。日後新增文案時，重新建置就會自動補字。另加一個建置檢查：頁面上有任何字不在子集內就失敗。
- 原本的 Noto Serif TC 自架分片移除。

### 8.8 第三版首頁的處理（使用者已核可，已執行）
- 第三版首頁（立體場景、門扇、震腳裂紋、淬火等）已整包 commit 在存檔分支 `archive/v3-depth`（dcbcef9）並推到 GitHub。只做保存，不合併、不上線。
- 新首頁在分支 `qi-homepage` 上開發，起點是已上線的 24bc050。只從存檔分支帶過來以下幾項：
  - 光點試作：`src/lab/qi/`、`src/pages/lab/qi.astro`
  - 剪影素材：`src/assets/silhouettes/`
  - 本文件
  - `astro.config.mjs` 的 sitemap 篩選
  - `.gitignore`
- 新首頁不沿用第三版的元件。若要參考，例如開場保底、`atmos` 體積光，從存檔分支讀取。

## 9. 需要的新素材

- **兒童剪影**：3–4 張，涵蓋兒童武術、防身格鬥、防身兵器。用同一套生圖管線產生，服裝與成人一致，人物約 8–12 歲。
- **教練剪影**：
  - 理想：從教練本人照片描出剪影。需要業主同意使用照片。
  - 在同意之前的退路：師資段的光點聚成一個通用的「抱拳行禮」剪影，教練資料以 DOM 卡片呈現。
- **核可流程**（使用者授權）：新素材由我們自行生成、檢查並決定去留，直接交付完成版本，不必逐張回報等核可。不合格的素材不得留在 runtime 路徑。成人拳架與兒童剪影是否正確，仍列入交付時給業主確認的清單。
- **朱印**：館名「六藝」，用崇羲篆體輸出成 SVG 或點陣後取樣。字型檔不放上網站（授權為 CC BY-ND，見字樣研究）。

## 10. 留給實作者決定

## 11. 驗收條件

- 三套測試（`npm test`、`npm run check`、`npm run test:e2e`）全過，e2e 連跑兩次。
- 以下這些用測試守住：
  - 首頁每一門已發布課程都有 DOM 標題與連結。
  - LINE 預約可從朱印開啟。
  - 大人／小孩切換與記憶。
  - 減少動態時全靜態。
  - 無 WebGL 時退回靜態圖。
  - 無水平溢出。
  - 首屏不在 three 到達前空白。
- 傳輸量符合 §5。
- 試作在 headless 下的 fps 不代表實機，上線前需要使用者在自己的電腦與手機上看過。
- fresh-context agent 獨立驗收通過。
