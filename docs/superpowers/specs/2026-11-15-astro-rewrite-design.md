# 六藝武術工作室網站：Astro 全站重寫設計

日期：2026-11-15　分支：`astro-rewrite`

標記說明：**【業主】** = 使用者或其朋友（教室負責人）明講的；**【我定】** = 設計者自行決定、可被推翻；**【待確認】** = 需要業主回覆，在回覆前照文中的暫行做法實作。

## 1. 為什麼做

舊站是 Forty 主題的 Jekyll 站，做到一半停工：配色是主題原色，與獅子 logo 脫節；課程架構與教室現在的分法不符；互動只有基本 hover 與淡入輪播。

教室負責人要一個「酷炫 7–8 分（滿分 10）的武術風格」形象網站，不想走人人都做的水墨，認同鬼武者官網那種方向，並且要能把網址貼出去當課程介紹。他要「看到畫面才有想法」，所以第一版的任務是**給出一個完整、可點、可貼連結的版本讓他挑毛病**，之後逐步修。【業主】

## 2. 目標、非目標、反目標

**目標**
- 用 Astro 全站重寫；舊專案只取文字與圖片。【業主】
- 視覺與互動大幅翻新，達到「7–8 分」：訪客第一眼感受到的是氣勢與質感，課程細節收在裡面一層。【業主】
- 課程依「大人／小孩 × 兵器／拳術／格鬥」呈現。【業主】
- 課程卡片：滑鼠移上去輪播該課程照片（每 2–5 秒一張，每門課最多 5 張）；點進去是文字簡介與課程影片。【業主】
- 效能好：手機上也順。【業主（選 Astro 的理由）】

**非目標（這一版不做）**
- ~~3D／WebGL 場景。~~（2026-11-15 使用者看過第一版後推翻：要 3D 金屬兵器與特殊互動，見 §15。）
- 線上報名、金流、會員、後台 CMS。
- 把收費與課表海報轉成文字表格（見 §7）。
- 多語系。
- 深色／淺色主題切換（舊站有，新站拿掉）。

**反目標（做到了也算失敗）**
- 看起來像水墨範本站，或像直接抄鬼武者官網（只借手法，不用其美術、文字、素材）。
- 為了炫而卡頓、手機發燙、首屏載入好幾 MB。
- 站上出現無法查證的教練資歷或編造的聯絡資訊。
- 用色塊、假圖示冒充照片或兵器素材。缺素材的地方寧可不放。

## 3. 限制

- 部署在 GitHub Pages，repo `Lawa0921/liu_yi`，目前沒有自訂網域，網址會是 `https://lawa0921.github.io/liu_yi/`，所以 Astro 要設 `site` 與 `base: '/liu_yi'`，所有內部連結與資源路徑都必須經過 base。【我定：base 寫在單一設定處，日後換自訂網域只改一行】
- 純靜態輸出，不需伺服器。
- 素材只有舊站的 35 張圖（約 7.3 MB），沒有影片、沒有 logo 向量檔、沒有去背兵器照。
- 開發環境 Node 24、npm 11。Astro 目前最新為 7.x；實作時以官方文件為準，不憑記憶寫 API。

**課程內文怎麼寫【我定】**：有三門課的定義已經變了，舊文不能照搬——散手技擊（舊文講的是八極與傳武哲學，現在是散打）、防身兵器（舊文講日常物品防身，現在是中國劍、苗刀、大槍的入門版）、以及三種兵器的子區塊（舊站沒有對應文字）。規則：
- 事實性內容（教什麼、給誰、誰教）**只能來自業主在上表給的描述**，或舊站中與新定義不衝突的段落。

**照片現況**：舊站的實拍照只涵蓋兒童課程、巴西柔術、瑜珈與場地。大人的中式兵器、八極專修、散手技擊**一張實拍都沒有**（舊站是拿教練海報頂替，新站不這樣做）。影響與暫行做法見 §6「缺照片時」。

## 6. 視覺與互動

### 中國武術與傳統元素【業主，2026-11-15 追加】

整站的辨識度要來自**中國武術與中國傳統**，不是日式（鬼武者只借「裱框、釘選、顆粒」的手法，造型語彙不可像日本武士、枯山水、蒔繪）。可用的語彙：
- **紋樣**：回紋（邊框與分隔線）、雲紋、海水江崖紋（logo 的獅子本來就踏浪，可延伸成頁面底部與分幕的波浪帶）、窗櫺格。
- **形制**：直書標題、對聯式的左右成對直排文字、朱紅印章（方印，用於分類標記與點綴）、匾額式的區塊標題、卷軸／冊頁式的展開進場。
- **武術本身**：兵器的輪廓（劍、苗刀、大槍）、八極拳的「八方」意象（以八向放射線或八角構圖帶出，不寫無法查證的拳理）、獅子（狻猊）logo。
- **用色**：黑、古金、米白為底，朱紅是印章色；可少量用石青或黛綠當冷色點綴。

禁忌：太極圖、八卦圖（業主說太極先當備案）、龍鳳等泛用「中國風」貼圖、任何 AI 味的假書法字。書法只用現有的 `text_transparent.png`（六藝武術工作室題字）。

### 色彩與字體

- 底色近黑；主色古金（約 `#B8924A`，以 logo 實際取色為準）；文字米白（約 `#EDE0C4`）；點綴用少量朱紅。全部定義成 CSS 變數。
- 標題用襯線明體（Noto Serif TC），內文用系統黑體。中文字型**不得整包自架**（一包 7 MB），用有分片載入的方式（例如 Google Fonts 的 unicode-range 分片，或 Astro 的字型功能），只載標題用到的字重。【我定】
- 全站一層極淡的動態顆粒，營造膠片質感。

### 固定外框

桌機上全站套一個固定的金色細線框：四角有角飾，上緣是獅徽與導覽，下緣是「預約體驗」與捲動提示；內容在框內捲動。角飾與分隔線用 SVG 向量繪製的幾何紋樣。【我定】手機上外框簡化成上下兩條細線加漢堡選單，展開為全螢幕選單。

### 課程卡片輪播

- 桌機：滑鼠移上去開始輪播，每 3 秒換一張，移開停止並回到第一張。
- 觸控裝置沒有 hover：卡片進入畫面中央時自動輪播，離開停止。【我定】
- 只有 0 或 1 張照片的課程不輪播；0 張時顯示以課程名稱大字為主的文字卡，不放替代圖。
- 輪播用的照片在卡片接近視窗時才載入。

### 缺照片時【待確認】

大人三門課目前沒有實拍照，所以在業主補照片之前：
- 預設的「大人」卡片是三張文字卡（課程名大字、分類單字、金線角飾），不輪播；切到「小孩」才看得到照片輪播。
- 首頁三幕以**字體設計為主體**：巨大的單字、直書課名、金線與顆粒的動態。有貼切實拍照的才放照片（兒童照只出現在標明小孩課程的位置，不拿來代表大人課程）。
- 兩種卡片（有照片、無照片）都要設計到位，文字卡不能看起來像壞掉的版位。

業主若能在第一版之前先給大人課程幾張照片，就直接放進去，上述退路自然用不到。

### 課程頁

頂部照片（可手動切換）、課程名稱與一句話簡介、內文、影片區、授課教練卡、返回總覽。影片用點擊後才載入播放器的輕量嵌入；**沒有影片網址時整個影片區不出現**。影片來源【待確認】（預設假設是 YouTube 連結）。

### 動態的規矩

- 捲動動畫用 GSAP ScrollTrigger，只在需要的頁面載入；其他頁面的進場效果用瀏覽器原生的方式（IntersectionObserver 加 CSS）。不使用平滑捲動函式庫。【我定】
- 使用者系統設定「減少動態」時：不釘選、不視差、不抖動顆粒、不自動輪播，內容直接顯示。
- 手機上三幕不釘選，改成一般捲動加進場效果。【我定：釘選在手機上容易卡，也佔太多捲動距離】
- 沒有 JavaScript 時，所有內容仍然看得到、連結都能點。

## 7. 收費與課表

## 15. 第二版追加：3D 金屬兵器與特殊互動（2026-11-15）

【業主】使用者看過第一版後的回饋：「效果不夠特別；做一些特殊的互動模式；刀劍和兵器可以建有金屬質感的建模。」本節推翻 §2 的「不做 3D／WebGL」與 §6「不上 3D」，其餘規則（中國傳統語彙、禁忌、不編造內容、減少動態、無 JS 可讀、效能門檻）全部照舊。以下除標【業主】外都是【我定】。

### 15.1 三件兵器的 3D 模型

- 中國劍、苗刀、大槍各一個模型，**用程式建模**（three.js 幾何：剖面擠出、車削、曲線掃掠），不下載現成模型、不用外部貼圖檔。理由：原創、檔案極小、可隨時調整。
- 造型要對，是**中國兵器**不是日本刀：
  - 中國劍：直身雙刃、劍脊（菱形剖面）、劍尖收鋒、劍格（護手）、劍柄纏繩、劍首、劍穗；另有劍鞘供出鞘動態用。
  - 苗刀：長身單刃微弧、長柄可雙手握、圓盤形護手、刀背有厚度、柄首；不可做成武士刀的樣子（不要菱形柄卷、不要方形鍔）。
  - 大槍：很長的白蠟桿（有錐度）、柳葉形槍頭帶脊、槍庫、紅纓。
- **金屬質感是重點**：刃面是拋光鋼（高金屬度、低粗糙度、順刃方向的細拉絲），刃口有倒角讓高光成一條線；配件是古金色銅件；柄是木或纏繩；纓穗朱紅。反光來自程式產生的攝影棚環境（數條長條燈，讓長刃上有流動的光帶），不載 HDR 檔。
- 光會跟著滑鼠／手指移動，刃上的光帶隨之流動。

### 15.2 特殊互動

1. **兵器台（首頁「兵器」那一幕）**：線稿換成真的 3D 兵器。捲動推進時劍出鞘、轉身、亮刃；可用滑鼠或手指拖曳轉動，放手有慣性並緩緩回正；一排「劍｜苗刀｜大槍」可切換，切換時舊兵器收走、新兵器入場。大槍入場要橫貫整個畫面。
2. **斬**：在首頁快速拖過畫面（滑鼠按住拖、手指滑）會留下一道金色刀光；幕與幕之間的轉場改成一道斜向刀光劈開畫面。刀光只是視覺，不擋點擊、不攔截捲動（手機上直向滑動仍是捲頁）。
3. **震腳（「拳術」那一幕）**：點一下或按空白鍵，八方紋自中心向外震開一圈，畫面微震。取八極拳發力的意象，不寫拳理。
4. **中式兵器課程頁**：三個子項（中國劍、苗刀、大槍）各有一個可轉動的 3D 兵器，補上大人兵器課沒有照片的缺口；首頁大人「中式兵器」卡片也用 3D 兵器取代純文字卡。
5. **首屏**：獅子 logo 上有一道跟著指標移動的金屬掃光。

### 15.3 規矩與退路

- three.js 只在需要 3D 的頁面、且接近 3D 區塊時才動態載入；首頁首屏傳輸量仍須 ≤ 1.5 MB（three 不算在首屏內），整頁 ≤ 5 MB。
- 手機也要有 3D（教室的訪客多半用手機），但降規格：像素比上限、陰影與後製關閉；離開畫面或分頁在背景時停止繪製。
- 不支援 WebGL 或建立失敗時，退回第一版的 SVG 線稿，頁面不能壞。
- 「減少動態」時：兵器以靜態姿勢呈現，不自動轉、不震、不出刀光；拖曳轉動仍可用。
- 無 JavaScript 時內容與連結照樣看得到（顯示線稿）。
- 動畫只在可見時跑；任何互動都不能造成頁面水平外溢或擋住導覽。
